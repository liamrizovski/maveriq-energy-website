# Maveriq Energy — Commercial Website

A responsive commercial website designed and developed for **Maveriq Energy**, a solar and battery installation business based in Wollongong, NSW, Australia.

🌐 **Live Website:** https://maveriqenergy.com.au/

## Project Overview

I designed, developed and deployed this website for a real business to establish its online presence, showcase its services and completed installations, and help potential customers make enquiries.

This project provided practical experience in front-end development, responsive web design, client communication and deploying a website for commercial use.

## Technologies Used

- **HTML5** — Website structure and content
- **CSS3** — Custom styling and responsive layouts
- **JavaScript** — Interactive website functionality
- **Netlify** — Website hosting and deployment

## Key Features

- Responsive layouts for desktop and mobile devices
- Custom-designed website interface
- Solar and battery service information
- Completed installation gallery
- Customer enquiry options
- Navigation between website sections

## My Responsibilities

- Designed and developed the website
- Implemented the front-end using HTML, CSS and JavaScript
- Created responsive layouts for different screen sizes
- Worked directly with the business to understand its requirements
- Tested and deployed the website using Netlify
- Managed website updates and improvements
